One sentence to convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

> If you can tell a friend about the app you wish existed, you can tell make.fun today — an AI agent will build a first version you can try, no code from you, and it only costs you a sentence.

## Run it

```sh
node main.ts
```

This writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). To write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
